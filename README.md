# 🎧 Harry Potter Audiobook Player

A multi-book, mobile-responsive web-based audiobook player designed for listening to the Harry Potter series with automatic progress tracking.

---

## ✨ Features

* **Multi-Book Navigation:** Easily navigate across all 7 books in the series.
* **Persistent Progress Tracking:** Uses `localStorage` to automatically save and restore your exact listening position across chapters and books.
* **Custom Dark Mode UI:** Sleek, modern, and accessible player interface with dynamic playlist selection.
* **Mobile Responsive:** Designed to look and function smoothly across mobile, tablet, and desktop devices.
* **Hosted on GitHub Pages:** Fast, free, and accessible globally from any web browser.

---

## 📂 File Architecture

* `index.html` — Main landing page & Book 1 player
* `book-2.html` through `book-7.html` — Individual player interfaces for Books 2 to 7
* Audio streams linked directly to direct media endpoints

---

## 🛠️ Built With

* **HTML5** (Structure & Audio API)
* **CSS3** (Custom UI styling & responsive layouts)
* **JavaScript (ES6)** (`localStorage` management & interactive DOM handling)
* **GitHub Pages** (Hosting & deployment)

---

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Open `index.html` in any web browser.
3. Choose a chapter and start listening!
